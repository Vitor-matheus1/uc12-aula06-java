ATIVIDADE PRÁTICA 01 - Arquitetura Java
====================================================================
1. Qual componente executa programas Java?
   Resposta: JVM (Java Virtual Machine / Máquina Virtual Java). Ela interpreta o bytecode (.class) e executa o programa.

2. Qual componente fornece ambiente de execução?
   Resposta: JRE (Java Runtime Environment / Ambiente de Execução Java). Contém a JVM e as bibliotecas necessárias para rodar aplicações Java.

3. Qual componente fornece ferramentas para desenvolvimento?
   Resposta: JDK (Java Development Kit / Kit de Desenvolvimento Java). Contém o JRE, a JVM, o compilador (javac) e demais ferramentas para desenvolver em Java.
